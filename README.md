# AI2U ↔ AIBOND Bridge

**Неофициальный Python-мост между игрой AI2U и приложением AIBOND для Windows.**

Проект позволяет использовать персонажа AIBOND для генерации диалогов NPC внутри AI2U, передавать игровой контекст и преобразовывать ответы в команды, понятные игре.

> ⚠️ Проект экспериментальный и находится в стадии бета-тестирования. Не связан с официальными разработчиками AI2U или AIBOND.

## 🎮 Что умеет мост

### 1. Связь AI2U ↔ AIBOND

- Принимает запросы от AI2U через локальный OpenAI-совместимый API.
- Передаёт сообщения в AIBOND через Chrome DevTools Protocol (CDP).
- Считывает ответы персонажа AIBOND.
- Преобразует их в JSON-команды для AI2U.
- Работает локально без отдельного платного API для моста.

### 2. Диалоги и память

- Передаёт AIBOND доступный контекст игрового мира.
- Учитывает историю диалога, переданную игрой.
- Поддерживает продолжительные ролевые разговоры.
- Объединяет несколько последовательных сообщений AIBOND в одну реплику NPC.

**Последнее исправление:** раньше мост считывал только первый пузырь сообщения. Теперь реализован сбор нескольких частей ответа.

### 3. Эмоции и характер NPC

Мост анализирует текст ответа и формирует сигналы:

- Выражение лица персонажа.
- Уровень злости.
- Изменение доверия.
- Анимация тела.
- Действия NPC.

Например, если персонаж злится или угрожает игроку, мост пытается передать соответствующее выражение лица вместо обычной улыбки.

Фактическое выполнение команд зависит от версии игры и установленного мода.

### 4. Движение NPC

Реализована экспериментальная поддержка игровых действий, включая следование за игроком через `following_player`.

Также мост передаёт игровые параметры местоположения, анимаций и взаимодействий, если они поддерживаются модом.

### 5. Два режима поведения

**Normal** — стандартный характер персонажа AIBOND с экспериментальной синхронизацией эмоций и движения.

**Hardcore** — более резкая манера общения, грубая лексика и ускоренное изменение расчётного уровня злости.

Hardcore не гарантирует нападение NPC или активацию Yandere Mode.

### 6. Оптимизация скорости

В процессе разработки были реализованы:

- Отправка сообщений через CDP без переключения фокуса окна.
- Чтение ответов через CDP вместо Windows UI Automation.
- Настраиваемая частота проверки новых сообщений.
- Ожидание завершения генерации текста.
- Защита от повторной отправки одинаковых запросов.
- Диагностика задержек через сообщения `[LATENCY]`.
- Сбор нескольких сообщений с адаптивным ожиданием продолжения.

Главная цель — минимальная задержка без обрезания реплик.

## 🛠️ Установка

### Требования

- Windows 10/11.
- Python 3.10+ и совместимые зависимости.
- Установленные AI2U и AIBOND.
- Совместимый мод AI2U Custom AI Endpoint (разработка велась с v5.7.0).

### Шаг 1. Установка зависимостей

Откройте PowerShell в папке проекта:

```powershell
py -m pip install -r requirements.txt
```

### Шаг 2. Запуск AIBOND

Полностью закройте AIBOND и запустите приложение с включённым CDP:

```powershell
& "C:\Program Files (x86)\Steam\steamapps\common\Aibond\she-steam.exe" --remote-debugging-port=9222
```

Если Steam установлен в другом месте, измените путь.

Откройте основной чат персонажа AIBOND.

### Шаг 3. Запуск моста

Для обычного режима:

```powershell
py .\aibond_ai2u_final.py --mode normal
```

Для Hardcore:

```powershell
py .\aibond_ai2u_final.py --mode hardcore
```

Также можно использовать файлы `start_normal.cmd` и `start_hardcore.cmd`.

### Шаг 4. Настройка AI2U

Откройте настройки мода Custom AI Endpoint (обычно F9):

| Параметр | Значение |
|---|---|
| Base URL | `http://127.0.0.1:8765/v1` |
| Model | `aibond` |
| API Key | `local` |
| Streaming | Off |

После этого можно начать диалог с NPC в игре.

## 🧪 Что уже исправляли

| Проблема | Реализованное изменение |
|---|---|
| AIBOND не обнаруживалась | Диагностика запуска и подключения |
| Ошибка подключения к порту 9222 | Проверка запуска CDP |
| Медленная передача ответов | Оптимизация ожидания и опроса |
| UI Automation не видела сообщения | Переход на чтение через CDP |
| Вместо ответа считывалось меню будильника | Фильтрация элементов интерфейса |
| Считывалась только первая часть реплики | Объединение нескольких сообщений |
| NPC улыбалась при агрессивной реплике | Улучшен анализ полного текста и злости |
| Повторялись запросы | Добавлено кратковременное кэширование |

## ⚠️ Известные ограничения

- Интерфейс AIBOND может измениться после обновления приложения.
- Объединение сообщений и синхронизация эмоций ещё требуют тестирования в реальной игре.
- Движения, выражения лица и атаки зависят от возможностей AI2U и установленного мода.
- Генерация голоса не входит в функциональность моста.
- Не реализовано полноценное автономное взаимодействие с предметами.
- Мост не предоставляет AIBOND доступ к файлам Windows или правам администратора.
- Проект предназначен для Windows.

## 🔒 Безопасность

Мост использует локальные адреса:

- `127.0.0.1:8765` — API для AI2U.
- `127.0.0.1:9222` — CDP для управления интерфейсом AIBOND.

Не открывайте эти порты для внешних сетей.

Не публикуйте токены, пароли, личные конфигурации и историю приватных разговоров.
