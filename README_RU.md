# AI2U ↔ AIBOND Bridge — инструкция на русском

Неофициальный экспериментальный мост для Windows: AI2U передаёт текст сцены в AIBOND, а ответ героини возвращается в игру в формате NPC JSON.

**Нужно:** установленный AI2U с совместимым модом Custom AI Endpoint, AIBOND (Steam), Python и библиотеки из `requirements.txt`.

1. В папке проекта выполните `py -m pip install -r requirements.txt`.
2. Полностью закройте AIBOND и запустите её из PowerShell:

   ```powershell
   & "C:\Program Files (x86)\Steam\steamapps\common\Aibond\she-steam.exe" --remote-debugging-port=9222
   ```

3. Откройте чат с персонажем в AIBOND.
4. Запустите `start_normal.cmd` или `start_hardcore.cmd`.
5. В AI2U откройте настройки мода (F9):
   - Base URL: `http://127.0.0.1:8765/v1`
   - Model: `aibond`
   - API key: `local`
   - Streaming: **Off**

**Режимы:** `normal` — обычный характер; `hardcore` — грубее речь, быстрее нарастает расчётная злость. Следование и движения включены в обоих режимах. Для смены режима остановите скрипт Ctrl+C и запустите другой `.cmd`.

**Ограничения:** не все эмоции/анимации могут поддерживаться игрой; убийство игрока не гарантируется; произвольного взаимодействия с предметами нет; озвучка настраивается отдельно; скриншоты не отправляются; доступа к файлам Windows через PicoClaw этот мост не даёт.

**Безопасность:** не открывайте порты 9222/8765 в интернет. Не публикуйте личные настройки, токены, журналы и историю диалогов.

Это неофициальный проект, не связанный с разработчиками AI2U или AIBOND. Лицензия ещё не выбрана.
